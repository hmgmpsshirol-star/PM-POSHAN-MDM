# MDM ದೈನಂದಿನ ವರದಿ — ಮೊಬೈಲ್ ಆಪ್ ಆಗಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುವ ವಿಧಾನ

ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ 4 ಫೈಲ್‌ಗಳಿವೆ:
- `index.html` — ನಿಮ್ಮ ವರದಿ ನಮೂನೆ (ಗೂಗಲ್ ಶೀಟ್ ಲಿಂಕ್ ಈಗಾಗಲೇ ಸೇರಿಸಲಾಗಿದೆ)
- `manifest.json` — ಆಪ್‌ನ ಹೆಸರು, ಐಕಾನ್ ಮಾಹಿತಿ
- `service-worker.js` — ಆಫ್‌ಲೈನ್/ಇನ್‌ಸ್ಟಾಲ್ ಸಪೋರ್ಟ್‌ಗಾಗಿ
- `icon-192.png`, `icon-512.png` — ಆಪ್ ಐಕಾನ್‌ಗಳು

ಇವೆಲ್ಲವನ್ನೂ GitHub Pages ಮೂಲಕ ಫ್ರೀ ಆಗಿ ಹೋಸ್ಟ್ ಮಾಡಿ, ನಂತರ ಫೋನ್‌ನಲ್ಲಿ "Home Screen" ಗೆ ಸೇರಿಸಿದರೆ ಅದು ಒಂದು ಆಪ್‌ನಂತೆ ಕೆಲಸ ಮಾಡುತ್ತೆ (ಐಕಾನ್ ಜೊತೆ, ಬ್ರೌಸರ್ ಬಾರ್ ಇಲ್ಲದೆ ತೆರೆಯುತ್ತೆ).

---

## ಹಂತ 1: GitHub ಖಾತೆ ಮತ್ತು Repository ರಚಿಸಿ

1. https://github.com ಗೆ ಹೋಗಿ, ಖಾತೆ ಇಲ್ಲದಿದ್ದರೆ ಉಚಿತವಾಗಿ ಸೈನ್ ಅಪ್ ಮಾಡಿ.
2. ಲಾಗಿನ್ ಆದ ಮೇಲೆ ಮೇಲ್ಭಾಗದಲ್ಲಿ **+** ಐಕಾನ್ → **New repository** ಒತ್ತಿ.
3. Repository name: `mdm-report` (ಅಥವಾ ನಿಮಗೆ ಇಷ್ಟ ಬಂದ ಹೆಸರು — ಸ್ಪೇಸ್ ಬೇಡ).
4. **Public** ಆಯ್ಕೆ ಮಾಡಿ (GitHub Pages ಉಚಿತ ಆಗಿ ಕೆಲಸ ಮಾಡಲು Public ಇರಬೇಕು).
5. **Create repository** ಒತ್ತಿ.

## ಹಂತ 2: ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಿ

1. ಹೊಸ repository ಪುಟದಲ್ಲಿ **"uploading an existing file"** ಎಂಬ ಲಿಂಕ್ ಒತ್ತಿ (ಅಥವಾ **Add file → Upload files**).
2. ಈ 5 ಫೈಲ್‌ಗಳನ್ನು (`index.html`, `manifest.json`, `service-worker.js`, `icon-192.png`, `icon-512.png`) ಎಳೆದು ಬಿಡಿ (drag & drop) ಅಥವಾ **choose your files** ಒತ್ತಿ ಆಯ್ಕೆ ಮಾಡಿ.
   - ⚠️ ಫೋಲ್ಡರ್ ಅಪ್‌ಲೋಡ್ ಮಾಡಬೇಡಿ — ಒಳಗಿನ ಫೈಲ್‌ಗಳನ್ನೇ ನೇರವಾಗಿ ಆಯ್ಕೆ ಮಾಡಿ (ಎಲ್ಲಾ ಫೈಲ್‌ಗಳು repository ಯ ಮೂಲ/root ನಲ್ಲೇ ಇರಬೇಕು, ಒಳಗಿನ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಅಲ್ಲ).
3. ಕೆಳಗೆ **Commit changes** ಒತ್ತಿ.

## ಹಂತ 3: GitHub Pages ಆನ್ ಮಾಡಿ

1. Repository ಒಳಗೆ ಮೇಲ್ಭಾಗದಲ್ಲಿ **Settings** ಟ್ಯಾಬ್ ಒತ್ತಿ.
2. ಎಡಗಡೆ ಮೆನುವಿನಲ್ಲಿ **Pages** ಒತ್ತಿ.
3. **Branch** ಎಂಬಲ್ಲಿ `main` ಆಯ್ಕೆ ಮಾಡಿ, ಫೋಲ್ಡರ್ `/ (root)` ಇರಲಿ, ನಂತರ **Save** ಒತ್ತಿ.
4. ಸ್ವಲ್ಪ ಸಮಯದ (1-2 ನಿಮಿಷ) ನಂತರ ಪುಟ ಮೇಲ್ಭಾಗದಲ್ಲಿ ಒಂದು ಹಸಿರು ಲಿಂಕ್ ಕಾಣುತ್ತೆ:
   ```
   https://<ನಿಮ್ಮ-ಯೂಸರ್ ಹೆಸರು>.github.io/mdm-report/
   ```
   ಇದೇ ನಿಮ್ಮ ಆಪ್‌ನ ಲಿಂಕ್.

## ಹಂತ 4: ಫೋನ್‌ನಲ್ಲಿ "ಆಪ್" ಆಗಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ

**Android (Chrome):**
1. ಮೇಲಿನ ಲಿಂಕ್ ಅನ್ನು Chrome ನಲ್ಲಿ ತೆರೆಯಿರಿ.
2. ಮೇಲೆ ಬಲಗಡೆ ⋮ (ಮೂರು ಚುಕ್ಕೆ) ಒತ್ತಿ → **"Add to Home screen"** ಅಥವಾ **"Install app"** ಆಯ್ಕೆ ಮಾಡಿ.
3. ಈಗ ಹೋಂ ಸ್ಕ್ರೀನ್‌ನಲ್ಲಿ ಒಂದು ಐಕಾನ್ ಬರುತ್ತೆ — ಅದನ್ನು ಒತ್ತಿದರೆ ನೇರವಾಗಿ ಆಪ್‌ನಂತೆ ತೆರೆಯುತ್ತೆ (ಬ್ರೌಸರ್ ಬಾರ್ ಇಲ್ಲದೆ).

**iPhone (Safari):**
1. ಲಿಂಕ್ ಅನ್ನು Safari ನಲ್ಲಿ ತೆರೆಯಿರಿ.
2. ಕೆಳಗೆ Share ಬಟನ್ (□↑) ಒತ್ತಿ → **"Add to Home Screen"** ಆಯ್ಕೆ ಮಾಡಿ.

---

## ಮುಂದೆ ಫಾರ್ಮ್‌ನಲ್ಲಿ ಬದಲಾವಣೆ ಮಾಡಬೇಕಾದರೆ

1. GitHub repository ಒಳಗೆ `index.html` ಒತ್ತಿ ತೆರೆಯಿರಿ.
2. ಪೆನ್ಸಿಲ್ ಐಕಾನ್ (✏️ Edit) ಒತ್ತಿ, ಬದಲಾವಣೆ ಮಾಡಿ.
3. ಕೆಳಗೆ **Commit changes** ಒತ್ತಿ.
4. 1-2 ನಿಮಿಷದಲ್ಲಿ ಫೋನ್‌ನಲ್ಲಿ ಇನ್‌ಸ್ಟಾಲ್ ಆಗಿರುವ ಆಪ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಹೊಸ ಆವೃತ್ತಿ ತೋರಿಸುತ್ತೆ (ಆಪ್ ಒಮ್ಮೆ ಮುಚ್ಚಿ ಮತ್ತೆ ತೆರೆಯಿರಿ).

## ಗಮನಿಸಿ
- ಇದು ಇಂಟರ್ನೆಟ್ ಬೇಡುವ ಆಪ್ — ವರದಿ ಸಲ್ಲಿಸಲು ಮೊಬೈಲ್ ಡೇಟಾ/ವೈಫೈ ಇರಬೇಕು (ಡಾಟಾ Google Sheet ಗೆ ಹೋಗಬೇಕಾಗಿರೋದ್ರಿಂದ).
- GitHub Pages ಸಂಪೂರ್ಣ ಉಚಿತ, ಯಾವುದೇ ಶುಲ್ಕ ಇಲ್ಲ.
